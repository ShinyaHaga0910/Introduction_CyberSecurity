用語集

日本語表記English意味
OSoperating systemハードウェアを管理し、プロセス、ファイル、アクセス制御、通信などの共通機能を提供する基本ソフトウェア（システム）
カーネルkernel実行中OSの中核。CPU、メモリ、デバイス、プロセス、ファイル、ネットワークなどを管理する

ディストリビューションdistributionLinuxカーネル、ツール群、パッケージ、初期設定、更新方針などを統合したOS体系。Ubuntuはその一例
コマンドラインcommand-line interface (CLI)文字列（テキスト）で指示と結果をやり取りする操作方法（インターフェース）
ターミナルterminal文字を入力し、結果を表示する画面・対話接続の環境
シェルshell入力された文字列を解釈し、コマンドを実行するプログラム。本演習環境では主にBashを使用する
ファイルfileデータ内容とメタデータを保持する、保存領域およびシステム表現の基本単位
ディレクトリdirectoryファイル名や他のディレクトリ名を対応付け、階層構造を構築する特殊なファイル

ポートport同一ホスト内で動作する複数の通信窓口（プロセス）を識別するための番号
ログlogプログラムやOSシステムが動作履歴、エラー、状態変化などを記録した情報
ローカルlocalSSHやSCPの接続・転送を開始する側の環境。本演習ではAWS CloudShellを指す

必須コマンド

目的コマンド・必要オプション注意すべき点・誤解操作後の確認
現在位置pwdプロンプトの表示文字列だけで判断せず、現在位置を確認する出力されたパスとホスト名・ユーザー名を照合する
移動cd PATH、cd ..、cd ~相対パスはカレントディレクトリ（現在位置）に依存するpwd
一覧ls -la、ls -ld DIR-l DIRはディレクトリ内の項目一覧を表示し、-ld DIRはディレクトリ自身の属性を表示する必要に応じてstatやtreeを併用する
階層表示tree PATH階層構造は把握できるが、ファイル内容やアクセス権までは網羅しないls -l等と併用する
ディレクトリ作成mkdir -p PATH意図しない階層パスを誤作成しないtree、ls -ld
コピーcp SOURCE DESTコピー元とコピー先の順序間違い、意図しない上書きに注意するcat、sha256sum
移動・改名mv SOURCE DEST移動先への不用意な上書きに注意するls
削除rm FILE通常のGUIのような「ごみ箱」はない。演習課題では安全のためrm -rfを使用しない実行前にpwdとlsで対象を確認し、実行後に不在を確認する
編集nano FILE意図したファイル名・パスで保存したか、未保存のまま終了していないか確認するCtrl+O、Enterで保存し、Ctrl+Xで終了後、catで内容を再確認する
内容表示cat FILE、less FILEバイナリファイルや極端に巨大なファイルを不用意にcatしないlessはqで終了する
検索grep [-F] PATTERN FILE-nは行番号を付加する。課題の提出要件に行番号が含まれていない場合は付けない出力された一致行と終了ステータスを確認する
末尾tail -n N FILE-nは出力行数を指定する（grep -nの行番号表示とは意味が異なる）行数と順序を確認する
標準出力を保存>、>>>は既存内容を切り詰めて（空にして）上書きする。入力元と同じファイルを指定すると内容を失うcat、wc -l
コマンド接続|標準出力だけが渡され、標準エラー出力（stderr）はパイプを流れないパイプで連結する前に、各コマンドを単独でも実行して動作を確認する
ユーザー/グループid [USER]、groups [USER]アカウントの登録情報と、起動済みセッションが保持する資格情報を区別する新しいセッション（ログインシェル）を開始した上でidを実行する
アカウントDBgetent passwd USER、getent group GROUPグループエントリの末尾一覧には、そのグループを主グループとしているユーザーが含まれない場合があるid USERと併用して確認する
ユーザー切り替えsudo su - USER、exitシェルが多重に入れ子になる点に注意する。演習用一般ユーザーにはsudo権限がない切り替えのたびにid -unやpwdで現在状態を確認する
1コマンドだけ別ユーザーsudo -u USER -- COMMANDrootでの実行成功を、対象ユーザーでも成功する証拠とみなさない実行直後にecho $?で終了ステータスを確認する
グループ追加usermod -aG GROUP USER-aなしで-Gを指定すると、記載しなかった既存の補助グループから除外されるid USERを実行し、新しいセッションで確認する
グループ削除gpasswd -d USER GROUPユーザー名とグループ名の指定順序に注意するid USER
所有者/グループ変更chown OWNER:GROUP PATH再帰的変更（-R）による影響範囲に注意するstat -c '%U:%G %a %n'
モード変更chmod MODE PATH安易に777を設定しない。ファイルとディレクトリで実行権限（x）の意味が異なるstatや別ユーザーでのtestコマンドで確認する
プロセス一覧ps -e -o ...、ps -p PID -o ...教科書の例示PIDをそのまま入力しないユーザー名、コマンド名、PIDが一致していることを照合する
シグナル送信kill -TERM PIDPID変数が空、0、負値、1（PID 1）でないことを確認する。PIDに対してpkillを使わないpsやサービスの稼働状態で終了を確認する
パッケージ情報・導入apt show NAME、sudo apt update、sudo apt install NAMEapt update（一覧更新）とapt upgrade（本体更新）の違いを理解する。演習環境で無関係な全体更新を行わないcommand -v、dpkg-query
サービス設定systemctl cat UNIT演習用のユニットファイルを直接編集しないUser、WorkingDirectory、ExecStartの各項目を確認する
サービス状態systemctl status/start/stopactive（起動中）であることだけで、機能全体が正常に動作していると判断しないis-active、MainPID、curlなどで多角的に確認する
起動時自動起動systemctl enable/disable UNIT即時起動（start/stop）と自動起動設定（enable/disable）は別軸であるis-enabled
Main PID取得systemctl show -p MainPID --value UNITMain PIDが0、空、または再起動前の古い値でないか注意するps -p PID
ソケット状態sudo ss -lntpアドレス、ポート番号、プロセスPIDをすべて照合するサービスのMain PIDと比較する
HTTP疎通curl -i URL、必要時--max-timeTCP接続の成功、HTTPステータスコード、応答本文の内容はそれぞれ個別に確認するステータスライン、本文、終了ステータスを確認する
ジャーナルログsudo journalctl -u UNIT --no-pager -n N過去の古い起動ログと、現在の実行ログを混同しない指定されたリクエストパスが記録されているか確認する
SSH接続ssh HOST、ssh HOST 'COMMAND'ホストエイリアスとDNSホスト名の違い、クォートによるローカル/リモートでの変数展開の違い、秘密鍵の保護に注意するid -un、hostname、pwdで接続先環境を確認する
SCPファイル転送scp SOURCE DEST転送元（source）と転送先（destination）の取り違え、不用意な上書きに注意する両環境でsha256sumを比較し、リモート側でstatを確認する
