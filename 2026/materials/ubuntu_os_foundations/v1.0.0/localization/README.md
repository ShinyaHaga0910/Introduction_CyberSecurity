# 多言語化の管理

## 原本

現時点の翻訳元は、内容を査読した`docs/ja/`である。`docs/en/`は未作成であり、将来の英語原本候補として扱う。英語版が完成した場合は、章単位で日本語・ウズベク語版との差分を再照合する。

## 対象言語

- `en`: 将来の英語原本候補（未作成）
- `ja`: 現在の翻訳元
- `uz`: ウズベク語（ChatGPT訳の初稿完成。母語話者による校閲待ち）
- `ru`: ロシア語（ChatGPT訳の初稿完成。ロシア語話者による校閲待ち）

## 同期単位

現存する日本語・ウズベク語・ロシア語の3言語で、章ファイル名、章番号、見出し順、図番号、表番号を対応させる。英語版を追加する場合も同じ規則を使う。コマンド、オプション、パス、ユーザー名、グループ名、サービス名、ポート番号、チェックID、URLは翻訳しない。

## 更新手順

1. 現在の翻訳元である日本語版を確認する。
2. `manifest.json`の翻訳元と状態を更新する。
3. `terminology.csv`で訳語を確定する。
4. 日本語、ウズベク語、ロシア語を章単位で更新する。
5. コードブロックと識別子が現行の翻訳元と一致することを自動確認する。
6. 各言語のHTML/PDFを生成して目視確認する。
7. 確認済みの言語だけを`approved`にする。

## 日本語

日本語表記は[`japanese-style-guide.md`](./japanese-style-guide.md)に従う。初学者向けの明確さと、他言語へ対応付けやすい一貫した用語を両立する。

## ウズベク語

ウズベク語版はChatGPTで翻訳し、[`uzbek-style-guide.md`](./uzbek-style-guide.md)と[`terminology.csv`](./terminology.csv)に従う。技術用語は英語表記を保ち、意味をウズベク語で説明する。本文12章・巻末・練習・課題・参照資料・図21点の初稿は完成した。ただし、日本語の練習P1～P6に後から追加した問題文は未反映である。構造照合とPDF表示確認は実施するが、ウズベク語話者による校閲が終わるまでは`approved`にしない。

## ロシア語

ロシア語版はChatGPTで翻訳し、[`russian-style-guide.md`](./russian-style-guide.md)と[`terminology.csv`](./terminology.csv)に従う。ウズベク語版の「IT用語を英語のまま保つ」規則を流用せず、定着したロシア語の専門用語を使う。固有名詞、コマンド、パス、IDは原文のまま保つ。本文12章・巻末・練習・課題・参照資料・図21点の初稿を作成した。ただし、日本語の練習P1～P6に後から追加した問題文は未反映である。ロシア語話者の校閲まで`approved`にしない。
