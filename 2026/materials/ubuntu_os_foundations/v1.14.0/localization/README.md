# 多言語化の管理

## 原本

翻訳原本は`docs/en/`とする。英語版の技術査読が完了するまでは、英語版を`approved`にしない。現在の日本語版は先行制作版であり、英語原本完成後に章単位で再照合する。

## 対象言語

- `en`: 英語原本
- `ja`: 日本語
- `uz`: ウズベク語
- `ru`: ロシア語

## 同期単位

4言語で、章ファイル名、章番号、見出し順、図番号、表番号を一致させる。コマンド、オプション、パス、ユーザー名、グループ名、サービス名、ポート番号、チェックID、URLは翻訳しない。

## 更新手順

1. 英語原本を修正する。
2. `manifest.json`のsource revisionを更新する。
3. `terminology.csv`で訳語を確定する。
4. 日本語、ウズベク語、ロシア語を章単位で更新する。
5. コードブロックと識別子が英語原本と一致することを自動確認する。
6. 各言語のHTML/PDFを生成して目視確認する。
7. 確認済みの言語だけを`approved`にする。

## 日本語

日本語表記は[`japanese-style-guide.md`](./japanese-style-guide.md)に従う。初学者向けの明確さと、他言語へ対応付けやすい一貫した用語を両立する。
